Wakudori 0.4.2

Wakudoriのマニュアル

同じ範囲を何度でも撮る, Windows用のスクリーンショットツールの使い方です.

Wakudoriとは

Windows標準のスクリーンショット(Snipping Toolなど)では, 撮るたびに範囲を選び直します. Wakudoriは前に撮った範囲を覚えていて, よく撮る範囲は名前を付けて残せます. 選び直す手間と, 位置のずれがなくなります.

  • 前と同じ範囲は, Enterだけ: ホットキーを押すと, 前に撮った範囲に枠が出ます(前回の範囲).
  • よく撮る範囲は, 名前で呼び出す: 撮る画面の上に名前が並びます. 下見もでき, クリックか数字キーで呼び出します(呼び出す).
  • いつ撮っても, 位置も大きさも同じ: 一度だけ矢印キーで1pxずつ合わせれば, 次も同じ範囲です(枠を調整する).
  • ファイル名で, 何の画像か分かる: 保存した範囲で撮ると, 範囲の名前がファイル名に付きます(ファイル名).

モニター全体の撮影と, 撮ってすぐの書き込みや黒塗りもできます(書き込む). 枠を置いたまま見張り, 中身が変わるたびに自動で撮ることもできます(見張って撮る). exe 1つで動き, 通信はしません(よくある質問).

こんな作業に

作業使い方
毎週, 毎月のレポートグラフごとに名前を付けておき, 毎回1, 2, 3と順に撮る. 並び順はレポートの順にそろえる
設定や修正の前後の比較1枚目を撮り, 直したあとにホットキーとEnter. 前回の範囲のまま撮れるので, 同じ位置で見比べられる
手順書の画像画像の大きさを決めた範囲を1つ作り, どの画面もその範囲で撮る. 画像の大きさがそろう
会議で共有された資料資料が映る範囲に枠を合わせてW. ページが送られるたびに1枚ずつ撮れる. 終わったらホットキーで止める
隠したいところがある画面呼び出してからEで撮り, Shift+ドラッグで黒く塗ってから貼る

できないこと

  • 範囲は画面上の位置で覚えます. ウィンドウを動かすと, 追いかけません(動かしたとき).
  • モニターをまたぐ範囲, スクロールした先, ウィンドウを選んでの撮影はできません.
  • 矢印や文字の書き込み, 文字の抽出, 録画, 時間をおいての撮影はありません. 標準のSnipping Toolと使い分けてください(一緒に使う).

はじめての撮影

レポートに貼るグラフを例に, 同じ範囲を撮り直し, 名前を付けて残すまでの流れです. 先にインストールとホットキーの登録を済ませてください.

  1. 1枚目: ホットキーを押し, 枠の外からグラフを囲むようにドラッグします. はみ出したら, 辺をクリックして矢印キーで合わせ, Enterで撮ります. クリップボードにも入るので, そのまま貼り付けられます.
  2. 2枚目: ホットキーを押すと, 同じ範囲に枠が出ています. Enterで撮ります.
  3. 名前を付ける: またホットキーを押し, Ctrl+Sで「売上グラフ」のように名前を付けてEnterを押します. もう一度Enterを押すと, 売上グラフ_(日時).pngで保存されます.
  4. 次からは: 間に別の範囲を撮っていても, ホットキー → 1 → Enterで同じ範囲を撮れます.

インストール

インストーラーはありません. ZIPを展開して, 中のbin\Wakudori.exeを起動するだけです. 管理者権限は要りません.

  1. ReleasesからWakudori-x.y.z.zipをダウンロードします.
  2. 好きな場所(例: ドキュメント\Wakudori)に展開します.
  3. 展開した中のbin\Wakudori.exeをダブルクリックして起動します.

gitを使う場合: cloneして, bin\Wakudori.exeを起動するだけで使えます(最新のリリースと同じexeで, 場所もZIPと同じです). gitで取ってきたファイルなら, 下の「WindowsによってPCが保護されました」は出ない見込みです(実機では未確認).

git clone https://github.com/maonthemoon/wakudori.git

新しい版にするときは, タスクトレイのメニューで「終了」してからgit pullし, もう一度bin\Wakudori.exeを起動します. 起動している間はexeを上書きできないので, git pullが失敗します.

v0.1.0のころにcloneした人へ: exeはリポジトリの直下からbin\Wakudori.exeに移りました. git pullのあとbin\Wakudori.exeを一度起動すると, 「PC起動時に起動」の登録先も新しい場所に直ります.

動作環境はWindows(Windows 11とWindows 10 22H2で動作を確認)と, .NET Framework 4.8です. .NET Framework 4.8はWindowsに標準で入っているので, 追加のインストールは要りません.

初めて起動するとき

Wakudoriには署名がないので, 初めて起動したときに「WindowsによってPCが保護されました」と出ることがあります. そのときは「詳細情報」を押し, 「実行」を押します.

ホットキーの登録

初めて起動すると, ホットキーの登録画面が出ます. 選択画面を開くのに使うキーを押し, Enterか「登録」で登録します. 登録すると, Wakudoriはタスクトレイに常駐します.

使えるキー例
Ctrl, Alt, Winのどれかと組み合わせたキーCtrl+Shift+S, Alt+Q
単独で使えるキー(Shiftとの組み合わせも可)F1〜F24, PrintScreen, Pause, ScrollLock
  • 文字キーやEnterなどは, 単独では登録できません. どのアプリでもそのキーが打てなくなるためです.
  • Escは選択画面を閉じるのに使うので, 登録できません.
  • ほかのアプリかWindowsが使っているキーは登録できません. 押しても登録画面に何も表示されないキーも, ほかで使われています.
  • キーボードのFnキーはWindowsから見えないので, 組み合わせには使えません.

ホットキーを登録しなかったときも, タスクトレイのアイコンをクリックすれば選択画面を開けます. 後から変えるときは, 設定画面の「起動キー」の「変更」を押します.

PCの起動時に起動

初めて起動したとき, 「PCの起動時に起動しますか」と聞かれます. 起動するようにすると, Windowsにサインインしたときに自動でタスクトレイに常駐します.

後から変えるときは, 設定画面の「PC起動時に起動」でオンとオフを切り替えます. 登録先はユーザーごとのスタートアップ(レジストリのHKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run)なので, 管理者権限は要りません. Wakudori.exeを別のフォルダーへ移したときは, 次に起動したときに登録先を新しい場所に直します.

撮る

  1. ホットキーを押すか, タスクトレイのアイコンをクリックします. 選択画面が開き, 範囲の外が暗くなります.
  2. 枠を撮りたい範囲に合わせます(枠を調整する).
  3. EnterかAを押します. Aは, 右手をマウスに置いたまま左手で押せる撮影キーです(設定画面で変えられます).

撮った画像は, クリップボードと画像の保存フォルダー(既定はピクチャ\Screenshots)の両方に出ます. 撮ったあとのお知らせや音はありません. 貼り付けるか, フォルダーを開いて確かめてください.

  • 撮るのは, ホットキーを押した瞬間の画面です. 選択画面には, そのときの止めた画面が出ます. Spaceを押すと動いている画面に切り替わり, Enterを押した瞬間の画面を撮ります. もう一度押すと止めた画面に戻ります.
  • 枠の線は撮る範囲のすぐ外側にあり, 画像には入りません. マウスカーソルも写りません.
  • Fを押すと, カーソルのあるモニター全体をすぐ撮ります. 前回の範囲は変わりません.
  • 撮らずに閉じるときはEscを押します(辺を選んでいるときは, 1回目で選択が外れます).

前回の範囲

選択画面を開くと, 前回撮った範囲がそのまま出ます. 同じ範囲を続けて撮るときは, 名前を付けなくても, ホットキーとEnterだけで撮れます.

  • 前回の範囲は, 撮ったときだけ更新します. Escで閉じたときは変わりません.
  • 初めてのときは, マウスカーソルがあるモニターの中央に800×600の枠が出ます.
  • モニターの構成が変わって前回の範囲が画面の外になったときは, マウスカーソルがあるモニターの中央に同じ大きさで出します. モニターより大きいときは, 収まる大きさに縮めます.

ファイル名

撮った範囲ファイル名
保存した範囲を呼び出し, 動かさずに撮ったyyyyMMdd_HHmmss_<範囲の名前>.png
それ以外(前回の範囲, 手で合わせた範囲, 呼び出してから少しでも動かした範囲)yyyyMMdd_HHmmss.png

ファイル名は撮った日時から始まるので, 名前の順に並べると撮った順になります. 例: 20261126_091500_KPI.png.

名前のうちファイル名に使えない文字(\ / : * ? " < > |)は_に置き換えます. 同じ名前のファイルがあるときは, 末尾に_2, _3...を付けます.

範囲を保存して呼び出す

保存する

  1. 選択画面で枠を合わせ, Ctrl+Sを押します.
  2. 名前を入力し, Enterか「保存」で保存します.

同じ名前の範囲があるときは, 上書きしてよいか聞かれます. もう一度Enterを押すか「上書き」を押すと上書きします. 保存したら, そのままEnterで撮ると, ファイル名に範囲の名前が付きます.

呼び出す

選択画面を開くと, マウスカーソルがあるモニターの上部に, 保存した範囲の名前が1行で並びます.

  • クリック: その範囲を呼び出します. 呼び出した名前はクレイ色になります. 枠を少しでも動かすと元の色に戻り, 名前のない範囲として扱います.
  • 数字キー: 先頭の9個には番号が付いていて, 1〜9で呼び出せます.
  • カーソルを乗せる: 枠がその範囲へ動き, 下見できます. 離れると元の枠に戻ります. 下見中にEnterを押すと, 見えている範囲を撮ります. ほかのキーは, 下見をやめて元の枠に戻してから働きます.
  • 「+N」: 1行に入りきらない分は「+N」にまとまります. カーソルを乗せると縦の一覧が開き, 「+N」と一覧から離れると閉じます. 一覧が長いときはホイールでスクロールします. Escでも閉じます.

保存した範囲が今の画面の外にあるとき(モニターを外したときなど)は, マウスカーソルがあるモニターの中央に同じ大きさで出します.

名前の変更, 削除, 並べ替え

  • 名前を変える: 名前をダブルクリックすると, その場で入力できます. Enterで決め, Escでやめます. ほかの場所をクリックしても決まります. ほかの範囲と同じ名前にはできません.
  • 削除する: 名前の右端にカーソルを合わせると×が出ます. 押すと確認が出て, 「削除」で一覧から消えます. これまでに撮った画像は消えません.
  • 並べ替える: 名前をドラッグすると, 入れる場所に細い棒が出ます. 離すとその順になり, 数字キーの番号も並び順どおりになります. 1行と「+N」の縦の一覧の間でも動かせます.

まとめて直したいときは, regions.jsonを直接書き換えることもできます.

キーボード

キー動き

Ctrl+矢印キー同じく10px動かす

枠は1つのモニターの中に収まります. モニターをまたぐ範囲は撮れません. 別のモニターへ動かすと, 枠全体がそのモニターの中に収まるように合わせます. 枠の幅と高さは16px以上です.

書き込む

選択画面でE(モニター全体ならShift+F)を押すと, 撮った画像に書き込む画面が開きます. 画像は, 撮ったのと同じ位置に同じ大きさで出ます.

操作動き
ドラッグペンで書く
Shift+ドラッグ四角く黒で塗りつぶす(隠す用)
パレットをクリック, 1〜7ペンの色を選ぶ(左から1〜7. 最初はオレンジ)
Ctrl+Z元に戻す
Ctrl+Yやり直す
Tabパレットを隠す, 出す(画像に重なってじゃまなとき)
Enter, Aクリップボードに入れ, <元の名前>_edit.pngで保存して閉じる. 何も書いていなければ, 元の画像をクリップボードに入れるだけ
Esc書き込みを捨てて閉じる. クリップボードには何も入れない

書き込む前の画像も, 撮った時点で保存フォルダーに残ります. 隠した部分がある画像を渡すときは, _editの付いたほうを渡してください.

見張って撮る

選択画面でWを押すと, 枠の範囲を見張ります. 中身が変わるたびに, 自動でPNGを保存します. 会議で共有された資料のページ送りを, 1枚ずつ撮り残すのに使えます.

  1. ホットキーを押し, 枠を資料の映る範囲に合わせてWを押します. 保存した範囲を呼び出したり, 名前に乗せて下見したりしてから押してもかまいません.
  2. 選択画面が閉じ, 枠の線と, 右上の札「見張り中 · 枚数 · 経過時間」だけが残ります. クリックは枠を通り抜けて下のアプリに届くので, そのまま操作を続けられます. ほかの窓が前に出ても, 1秒ほどで枠が前に戻ります.
  3. 終わったら, もう一度ホットキーを押します(選択画面は開きません). タスクトレイのメニューの「見張りをやめる」でも止められます.
  4. 右下に「見張りを終えました」と撮った枚数が出ます. クリックすると保存先のフォルダーが開きます. 数秒で消えます.
  • 1秒ごとに範囲を見比べ, 変わったあと2回続けて同じだったら撮ります. ページが送られてから約2秒で撮れます. 始めた直後の画面も1枚目として撮ります.
  • マウスのポインタや入力のカーソルのような小さな変化では撮りません. ページ送りや, 箇条書きが1行増えるくらいの変化で撮ります. 動画やアニメーションのように動き続けている間は, 落ち着くまで撮りません.
  • 画像は保存先の見張り_yyyyMMdd_HHmmssのフォルダーに001.png, 002.png...の順で入ります. クリップボードには出しません. 枠の線と札は画像に入りません.
  • 見張った範囲は, 前回の範囲になります.
  • 2時間たつか500枚撮ると, 自動で止まります.
  • 会議アプリが保護していて真っ黒に写る画面は撮りません. 飛ばしたときは, 終わったときの知らせに書きます.
  • 見張り中は, タスクトレイのアイコンに赤い点が付き, カーソルを乗せると撮った枚数が出ます.
  • 保存先に書けなくなったときは, 見張りを止めて理由を知らせます.

撮影キーにはWを使えません. settings.jsonのcaptureKeyにWが書いてあるときは, お知らせを出してAを使います.

タスクトレイのメニュー

タスクトレイのアイコンをクリックすると, 選択画面が開きます. 右クリックでメニューが出ます. カーソルを乗せると, バージョンとホットキーが出ます.

メニュー動き
見張りをやめる見張りを止める. 見張り中だけ先頭に出る(見張り中は「撮影」を押せない)
撮影選択画面を開く
設定設定画面を開く
画像保存フォルダーを開く撮った画像のフォルダーを開く
マニュアルこのマニュアルを開く
終了Wakudoriを止める. 書き込みの途中なら, 捨ててよいか確かめる. 見張り中なら, 見張りを止めてから終わる

Wakudoriは2つ同時には起動しません. 起動中にもう一度Wakudori.exeを開くと, 「すでに起動しています」と出ます.

設定画面

タスクトレイのメニューの「設定」で開きます. 変えた設定はその場で反映され, 保存のボタンはありません. 反映すると, 画面の下に「反映しました」と出ます.

区分項目内容

ホットキー撮影キーEnterのほかに撮るキー. 英字から選ぶ(E, F, Wは除く). 既定はA
起動PC起動時に起動PCの起動時に起動するかを切り替える

下の「設定フォルダーを開く」で, 設定ファイルのある%APPDATA%\Wakudoriを開けます. Escか「閉じる」で閉じます.

古い画像の自動整理

「古い画像をごみ箱へ移す」をオンにすると, Wakudoriで撮った画像を, 撮ってから指定の日数がたったらごみ箱へ移します. ごみ箱へ移すだけなので, ごみ箱を空にするまでは元に戻せます.

  • 移すのは, Wakudoriが撮って記録した画像だけです(v0.4.0より前に撮った画像は記録がないので移しません).
  • 撮ったあとに別のフォルダーへ移した画像, 名前を変えた画像, 開いて直した画像は移しません.
  • ネットワーク上や外付けのドライブなど, ごみ箱のない場所の画像は移しません.
  • 見張りで撮った画像は, 1回の見張りのフォルダーごとに扱います. 日数は見張りを終えた日から数えます. 中身が見張りで撮った連番のPNGだけならフォルダーごとごみ箱へ移し, ほかのファイルやフォルダーを入れていたら消さずに記録から外します.
  • オンにしたとき, すでに日数を過ぎた画像があれば, 何枚移すかを出して確かめます.
  • 整理するのは, 起動の1分後と, その後6時間ごとです. ほかのアプリで開いているなどで移せなかった画像は, 次の回にまた試します.

設定ファイル

設定と保存した範囲は, %APPDATA%\Wakudoriにあります. 設定画面の「設定フォルダーを開く」で開けます. ふだんは設定画面で変えれば十分です. どちらもUTF-8のJSONで, メモ帳などで編集できます.

settings.json

{
  "hotkey": "Ctrl+Shift+S",
  "saveDir": "%USERPROFILE%\\Pictures\\Wakudori",
  "captureKey": "A",
  "autoDelete": false,
  "autoDeleteDays": 30
}
項目内容
hotkey登録したホットキー. ふだんは設定画面の「起動キー」で変える. 手で書き換えたときは, Wakudoriを起動し直すと反映される
saveDir画像の保存先. 書かなければピクチャ\Screenshots. %USERPROFILE%などの環境変数を使える. 選択画面を開くたびに読み直す
captureKey撮影キー. Enterと同じく撮り, 書き込む画面では完了する. 英字1文字(E, F, Wは使えない). 書かなければA. 使えないキーを書くと, お知らせを出してAを使う. 選択画面を開くたびに読み直す
autoDelete古い画像をごみ箱へ移すか(trueかfalse). 書かなければfalse(古い画像の自動整理)
autoDeleteDays撮ってから何日たった画像を移すか. 1〜365の整数(選択肢にない日数も書ける). 書かなければ30
ⓘ

JSONの中では, パスの\を\\と2つ重ねて書きます.

regions.json

{
  "last": { "x": 588, "y": 180, "width": 236, "height": 278 },
  "regions": [
    { "name": "売上グラフ", "x": 216, "y": 180, "width": 376, "height": 278 },
    { "name": "KPI", "x": 216, "y": 96, "width": 608, "height": 84 }
  ]
}
  • lastは前回撮った範囲, regionsは保存した範囲です. regionsの並び順が一覧の順になります.
  • 座標は画面の物理ピクセルです(表示スケールで拡大する前の値). xとyは左上の位置で, 複数のモニターをまとめた座標です.
  • 名前が空のもの, 幅か高さが0以下のものは読み飛ばします.
  • 選択画面を開くたびに読み直すので, 書き換えたあとWakudoriを起動し直す必要はありません.
!

最後の項目の後ろに,を付けると, JSONの誤りとして読めなくなります. 読めないときはお知らせが出て, そのファイルを上書きしないようにします(直し方).

captures.log

Wakudoriが撮った画像の記録です(見張りで撮った画像は, フォルダーごとに1行). 古い画像の自動整理で, Wakudoriが撮った画像かどうかを見分けるのに使います. 指定の日数を過ぎた記録は, 自動整理がオフでも外します. ごみ箱へ移せなかった画像の記録は, 次の回のために残します. 手で編集する必要はありません.

error.log

想定外のエラーが起きると, 同じフォルダーのerror.logに日時とバージョン, エラーの内容を書きます. このPCに残すだけで, どこにも送りません. 不具合を知らせるときに添えると, 原因を調べやすくなります. フォルダーの場所やユーザー名が含まれることがあるので, 添える前に中身を確かめてください. 消してもかまいません.

アンインストール

  1. PCの起動時に起動するようにしていたら, 設定画面の「PC起動時に起動」をオフにします.
  2. タスクトレイのメニューの「終了」で止めます.
  3. 展開した(またはcloneした)フォルダーを消します.
  4. 設定と保存した範囲も消すなら, %APPDATA%\Wakudoriを消します.

撮った画像(ピクチャ\Screenshotsなど)は残ります.

よくある質問

ウィンドウを動かしたら, 範囲も動く?

動きません. 範囲は画面上の位置で覚えます. 撮るウィンドウは最大化しておくか, いつも同じ位置に置いてください. ずれたときは, 呼び出してから枠の内側をドラッグして合わせ, Ctrl+Sで同じ名前に上書きします. モニターの解像度や拡大率を変えたときも, 合わせ直してください.

Snipping Toolと一緒に使える?

使えます. Snipping ToolはWin+Shift+Sのまま, Wakudoriには別のホットキーを登録してください. 何度も撮る範囲はWakudori, 一度きりの切り取りや文字の抽出, 録画はSnipping Toolと分けられます.

画像や設定を, どこかに送る?

Wakudoriは通信しません. アップロードも, 自動更新も, 利用状況の送信もありません. ただし, 保存先のピクチャがOneDriveなどの同期の中にあると, そのソフトが画像を同期します. 避けたいときは, 設定画面の「保存先」で同期の外のフォルダーに変えてください.

「WindowsによってPCが保護されました」と出る

Wakudoriには署名がないため, 初めて起動したときに出ることがあります. 「詳細情報」→「実行」で起動できます. 会社のPCなどで実行が禁止されている場合は, 管理者に確認してください.

ホットキーを登録できない

ほかのアプリかWindowsがそのキーを使っています. 別のキーを選ぶか, そのキーを使っているアプリの設定を変えてください. 単独のキーはF1〜F24, PrintScreen, Pause, ScrollLockだけ使えます(ホットキーの登録).

PrintScreenを押すとSnipping Toolが開く

WindowsがPrintScreenキーを使っています. Windowsの「設定」→「アクセシビリティ」→「キーボード」で, PrintScreenキーで画面キャプチャ(Snipping Tool)を開く設定をオフにしてから, 設定画面の「起動キー」の「変更」で登録し直してください. 設定の名前と場所は実機では未確認です. 見当たらないときは, 「設定」の検索欄に「PrintScreen」と入れて探してください.

拡大率の違うモニターを並べて使える?

表示スケール(拡大率)は100%でも150%でも, 範囲を画面のピクセルどおりに撮れることを確かめています. 拡大率の違うモニターを2台並べた環境でも確かめています. うまく撮れないときはGitHubのIssuesで知らせてください.

「範囲の保存ファイルを読めません」と出る

regions.jsonのJSONに誤りがあります. お知らせに, 誤りの場所の手がかりが出ます. よくある原因は, 最後の項目の後ろの,, 閉じていない"や}です.

読めない間は, 保存した範囲と前回の範囲を使わずに選択画面を開きます. ファイルを壊さないよう, Ctrl+Sでの保存や, 前回の範囲の更新もしません. ファイルを直すか消してから, 選択画面を開き直してください. 消した場合は, 保存した範囲はなくなります.

settings.jsonが読めないときも同じで, 既定の設定で動き, ファイルは上書きしません.

「クリップボードに入れられませんでした」と出る

ほかのアプリ(リモートデスクトップなど)がクリップボードを使っています. 画像はファイルに保存してあるので, お知らせに出た場所から開いてください. 逆に「画像を保存できませんでした」と出て, クリップボードに入っていると書かれていれば, そのまま貼り付けられます.

撮った画像はどこ?

クリップボードと, 画像の保存フォルダー(既定はピクチャ\Screenshots)にあります. 見張りで撮った画像は, その中の見張り_で始まるフォルダーにあります. タスクトレイのメニューの「画像保存フォルダーを開く」で開けます.
