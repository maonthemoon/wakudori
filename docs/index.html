Windows用のスクリーンショットツール

同じ範囲を, 何度でも撮る.

前回の範囲を覚えていて, ホットキーとEnterだけで撮り直せます. よく撮る範囲は, 名前を付けて保存できます.

ダウンロード → マニュアル

動くデモ

Snipping Toolとの違い

Snipping Toolでは, 撮るたびに範囲をドラッグで選び直します. Wakudoriは, 範囲を使い回すための道具です.

前回の範囲が, そのまま出る

ホットキーを押すと, 前に撮った範囲に枠が出ます. そのままEnterで, 同じ範囲を撮り直せます.

範囲に名前を付けて, 呼び出す

Ctrl+Sで保存. 名前にカーソルを乗せると枠が動いて下見でき, クリックか数字キー1〜9で呼び出せます.

1px単位で合わせる

辺や角はどこでもつかめます. 選んだ辺は矢印キーで1px, Ctrl+矢印キーで10pxずつ動きます.

貼り付けとファイルの, 両方に出す

撮った画像はすぐ貼り付けられ, ピクチャ\ScreenshotsにもPNGで残ります. ファイル名には範囲の名前が付きます.

軽い. exe 1つで動く

インストールも管理者権限も要りません. Windowsに標準で入っている.NET Framework 4.8だけで動きます.

表示スケールと複数モニターに対応

拡大率が100%でも150%でも, 画面のピクセルどおりに撮れます. 拡大率の違うモニターを並べても使えます.

はじめかた

  1. ダウンロードReleasesからWakudori-x.y.z.zipを落として展開します.
  2. 起動bin\Wakudori.exeをダブルクリック. 「PCが保護されました」と出たら「詳細情報」→「実行」.
  3. ホットキー使いたいキー(例: Ctrl+Shift+S)を押して登録すれば準備完了です.

Windows 11とWindows 10 22H2で動作を確認しています. gitで入れる方法はREADMEに, 詳しい使い方とアンインストールはマニュアルにあります.
