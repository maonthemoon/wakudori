Windows用のスクリーンショットツール

同じ範囲を, 何度でも撮る.

ホットキーを押すと, 前に撮った範囲がそのまま出ます. あとはEnterで撮るだけ. よく撮る範囲は, 名前を付けて残せます.

動くデモ

もう, 範囲を選び直さない

Windows標準のスクリーンショットでは, 撮るたびに範囲を選び直します. 手間がかかり, 前の画像と少しずつずれます. Wakudoriは, 一度決めた範囲を使い回します.

前と同じ範囲は, Enterだけ

前に撮った範囲に, はじめから枠が出ています. 準備は要らず, 2枚目からもうドラッグしません.

よく撮る範囲は, 名前で呼び出す

Ctrl+Sで名前を付けると, 撮る画面の上に並びます. 乗せれば下見, クリックか数字キー1〜9で呼び出しです.

いつ撮っても, 位置も大きさも同じ

一度だけ, 矢印キーで1pxずつ合わせておけば, 来週も同じ範囲です. 先週の画像と, そのまま見比べられます.

ファイル名で, 何の画像か分かる

保存した範囲で撮ると, 20261126_091500_KPI.pngのように日時の後ろに範囲の名前が付きます. 名前の順に並べれば, 撮った順です.

Windows標準との使い分け

何度も撮る範囲はWakudori, 一度きりの切り取りや文字の抽出, 録画は標準のSnipping Tool. ホットキーを分ければ, 両方使えます.

Windows標準の列は, Windows 11のSnipping Toolとキー操作です. 公式の説明と, Quick markupは報道で, 2026年11月に確かめました. 版によって違うことがあります.

向いている作業, 向いていない作業

向いている

  • 毎週, 毎月のレポートに, ダッシュボードの同じグラフを貼る
  • 設定や修正の前後を, 同じ範囲で撮って見比べる
  • 手順書の画像を, 大きさをそろえて撮る
  • 1つの画面から, 決まった何か所かを続けて撮る
  • 会議で共有された資料を, ページごとに撮り残す(Wで見張る. 撮影や保存が許されている資料に)

向いていない

  • 動かしたウィンドウを追いかけて撮る(範囲は画面上の位置で覚えます)
  • スクロールしないと見えないところまで, 1枚に撮る
  • 矢印や文字を入れて, 説明の画像を作る
  • 2つのモニターにまたがる範囲を, 1枚に撮る
  • 動画を撮る, 動き続ける画面を撮り続ける

試すのも, やめるのも簡単

置くだけで動く

約130KBのexe 1つ. インストールも管理者権限も要りません.

どこにも送らない

Wakudoriは通信しません. ソースも公開しています.

消せば終わり

自動起動を外して終了し, 置いたフォルダーと設定のフォルダーを消すだけ. 標準のスクリーンショットの設定は変えません.

はじめかた

  1. ダウンロードReleasesからZIPを落として, 好きな場所に展開します.
  2. 起動bin\Wakudori.exeをダブルクリック. 署名がないので, 「PCが保護されました」と出たら「詳細情報」→「実行」.
  3. ホットキー使いたいキー(例: Ctrl+Shift+S)を押して登録します.
  4. 撮るホットキーを押して枠を合わせ, Enterで撮ります. 次からは同じ範囲が出ます.

Windows 11とWindows 10 22H2で動作を確認しています. 表示スケールと, 拡大率の違うモニターにも対応しています. gitで入れる方法はREADMEに, 詳しい使い方とアンインストールはマニュアルにあります.
